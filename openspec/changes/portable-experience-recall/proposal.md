# Portable experience recall

## Why
PR10 supplies eleven merged source packages, but verified/trusted handles are process-local and expire with live evidence. The inherited goal is future-session/model reuse: persisted flags or snapshots must not restore current authority.

## What Changes
Extend the existing learning seam with eligible-handle-only portable signed historical archives, explicit host Hindsight query/document ports, independent-process signature/origin/scope validation, revocation-aware historical selection and character-bounded non-executing context. Add explicit observed-only import; later current verification still requires fresh authoritative receipts and cannot reuse stored status/old clocks.

## Impact
Additive existing learning package APIs and maintained docs/spec/tests. No real keys, bank/network writes, default Pi injection, executable replay, model calls or operational activation. Signer/client callbacks and pinned archive-origin public keys are explicit trusted-host configuration.
