## Why

caller-supplied SHAs are not authoritative evidence. Learning must not turn
observation, model votes, or a stored status into execution permission.

- Add explicitly confirmed, digest-bound Hindsight promotion through a trusted injected transport.
- Add bounded failure classification, lifecycle management, and non-executing replay/comparison.

- Add repeatable clean-consumer, minimum-runtime, security, packaging and CI checks.

## Impact
Additive packages; preserve the eight existing package runtimes and tests.
No automatic Pi hooks, live owner wiring, signing keys, Hindsight writes, model
execution, training, gate/guard changes, registry publication or production changes.

must not be silently upgraded to signed authority. Host integration is explicit.
