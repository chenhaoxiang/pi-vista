# Explicit Pi observation and experience preview

## Why
The source evidence, historical recall and explicit store/file addons are delivered, but Pi does not yet have an opt-in runtime bridge for observation and reviewing guidance. User approval covers this bounded source slice, not default activation, owner producer deployment, real-bank writes or execution.

## What changes
Add one explicit subpath, @pi-vista/learning/pi, with a host-configured public-Pi-compatible extension factory and a read-only/programmatic controller. Observe safe metadata only, display bounded authentic historical script/step previews, record an exact explicitly chosen preview without injecting it, and distinguish observed/history/current proof/MISSING. Reuse the existing core, portable recall and evidence verifier, not a second trust system.

## Scope
One tightly coupled optional run-state/preview epoch seam in the existing learning package. The root learning/adapter/CLI APIs, original assertions and gate/guard decisions stay unchanged. No SDK runtime dependency, autoload manifest, .pi resource, production keys, raw payload storage, signing, Hindsight retain, default bank, model call or executable replay. Only an additive export map, new source/tests/fixtures and maintained owner documentation are expected.
